# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-18

### Added
- Initial release of Schemaflow.
- VS Code extension that generates TypeScript interfaces from JSON Schema files on save, with live preview.
- Basic CLI for generating TypeScript interfaces from a JSON Schema file.
- Utility modules for loading schemas and mapping JSON Schema types to TypeScript.

### Fixed
- None.

### Known Issues
- The extension currently only supports a subset of JSON Schema features.
- Live preview may lag for very large schemas.
